# 가게 정산 관리 시스템

가게의 일별/월별 수익과 비용을 기록하고 관리하는 정산 관리 시스템입니다.

## 주요 기능

### 필수 기능
1. **거래 입력**
   - 수익(매출) 기록: 일자, 거래 내용, 수입 금액, 수입 유형, 매출 채널 등
   - 비용(지출) 기록: 일자, 거래 내용, 비용 금액, 계정 과목 등
   - 공급가액/VAT 입력 지원 (부가세 신고용)

2. **거래 목록 조회**
   - 모든 거래 내역 표시
   - 일자, 거래 내용, 금액, 유형 등 상세 정보 표시

3. **검색 및 필터링**
   - 일자 범위 필터링
   - 거래 유형별 필터링 (수익/비용)
   - 수입 유형별 필터링
   - 계정 과목별 필터링
   - 거래 내용/거래처 검색

4. **계정 과목 관리**
   - 기본 계정 과목: 식재료비, 인건비, 임차료, 공과금, 수수료, 소모품비, 광고선전비
   - 사용자 정의 계정 과목 추가/수정/삭제
   - 계정 과목별 고정비/변동비 자동 분류

### 부가 분석 기능
1. **대시보드 - 월별 핵심 지표**
   - 당월 총수익, 당월 총비용, 당월 순수익 표시
   - 전월 대비 변화율 표시
   - 전년 동월 대비 변화율 표시

2. **비용 구조 시각화**
   - 고정비/변동비 비율 파이 차트
   - 고정비/변동비 금액 표시

3. **매출 추이 분석**
   - 최근 6개월 수익/비용/순수익 막대 그래프
   - 월별 비교 리포트

## 설치 및 실행

### 사전 요구사항
- Node.js 18.0.0 이상
- npm 또는 yarn

### 설치
```bash
npm install
```

### 개발 서버 실행
```bash
npm run dev
```

개발 서버가 실행되면 브라우저에서 `http://localhost:5173` (또는 터미널에 표시된 주소)로 접속하세요.

### 프로덕션 빌드
```bash
npm run build
```

빌드된 파일은 `dist` 폴더에 생성됩니다.

## 데이터 저장

모든 데이터는 브라우저의 LocalStorage에 저장됩니다. 브라우저의 데이터를 삭제하면 모든 기록이 삭제되므로 주의하세요.

## 기술 스택

- **프론트엔드**: React 18, TypeScript
- **빌드 도구**: Vite
- **차트 라이브러리**: Recharts
- **날짜 처리**: date-fns
- **스타일링**: CSS (모바일 반응형 지원)

## 사용 방법

1. **거래 등록**
   - 상단 메뉴에서 "거래 등록" 클릭
   - 수익 또는 비용 유형 선택
   - 필수 항목 입력 후 "등록" 버튼 클릭

2. **거래 목록 조회**
   - 상단 메뉴에서 "거래 목록" 클릭
   - 필터를 사용하여 원하는 거래 검색

3. **대시보드 확인**
   - 상단 메뉴에서 "대시보드" 클릭
   - 월 선택 드롭다운에서 원하는 월 선택
   - 월별 수익/비용/순수익 및 분석 차트 확인

4. **계정 과목 관리**
   - 상단 메뉴에서 "계정 과목 관리" 클릭
   - 계정 과목 추가, 수정, 삭제 가능 (기본 항목은 삭제 불가)
